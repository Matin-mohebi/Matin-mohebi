# Matin AI for Android

A lightweight Persian AI assistant app built with Kotlin and Jetpack Compose.

## Features
- Persian chat interface
- OpenAI Chat Completions API connection
- API key entered and stored locally on the device
- Designed for lightweight Android devices

## Build
GitHub Actions builds a debug APK when files in `MatinAIAndroid/` change. Open the Actions tab and download the `MatinAI-debug-apk` artifact from the completed workflow run.

## Setup
1. Install the APK on your Android phone.
2. Open Settings inside the app.
3. Enter your own API key for a compatible service.
4. Save and start chatting.

API use may incur charges and depends on service availability. The app does not include an API key. Never commit secrets to GitHub.

Package: `ir.matincode.matinai`
